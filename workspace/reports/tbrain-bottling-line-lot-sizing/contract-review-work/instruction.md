The bottling company plans its four sites with `/app/planner/plan_site.py`, which each day fills exactly what that day is short of on the first line with room, and its plans pay for a changeover on almost every run and still leave customers waiting. For each site in `/app/sites/` (`dorset`, `kent`, `fife` and `tyne`), write a production plan to `/app/plans/<site>.json` that follows `/app/docs/production-rules.md` and costs no more than the site's target in `/app/sites/targets.json`. Each target is the cost of the best plan the planning office has found for that site.

`/app/tools/check_plan.py` checks a plan under the rules and prints its cost; the rules document gives the file format. Only the four plan files are used, and how you produce them is up to you, but there is no network and nothing can be installed, so any search you run has to use what is already here (Python 3.13 and its standard library).
