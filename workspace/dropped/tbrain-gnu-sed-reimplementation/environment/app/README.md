# pysed

A Python replacement for GNU sed 4.9, for the minimal target images that
ship without sed. This development image still has GNU sed as /bin/sed.

- `pysed/sed.py` — the command (`python3 /app/pysed/sed.py ...`)
- `docs/sed.txt` — the GNU sed manual
- `docs/scope.md` — the part of GNU sed that pysed covers
