The apron office allocates stands with `/app/planner/plan_day.py`, which takes the turns in order of arrival and puts each on the first free stand it fits, and its plans send transfer passengers on long walks between piers and bus more flights than they need to. For each day in `/app/days/` (`day-1`, `day-2`, `day-3` and `day-4`), write a plan to `/app/plans/<day>.json` that follows `/app/docs/stand-rules.md` and costs no more than the day's target in `/app/days/targets.json`. Each target is the cost of the best plan the office has found for that day.

`/app/tools/check_plan.py` checks a plan under the rules and prints its cost; the rules document gives the file format. Only the four plan files are used, and how you produce them is up to you, but there is no network and nothing can be installed, so any search you run has to use what is already here (Python 3.13 and its standard library).
