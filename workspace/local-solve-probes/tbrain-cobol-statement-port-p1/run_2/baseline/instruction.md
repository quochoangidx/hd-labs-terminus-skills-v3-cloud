The quarterly water statements are still printed by the COBOL job step `/app/legacy/WBILL.cbl`, with its copybooks beside it and its run notes in `/app/legacy/RUNBOOK.md`. Write its replacement in `/app/port/wbill.py`: Python 3, standard library only, run as `python3 /app/port/wbill.py <input> <output>`. For any input file the job step accepts, the port must write exactly the bytes the job step writes to `STMTOUT` when it is built and run as the run notes describe. `/app/legacy/samples` holds a production extract and the statement file the job step produced from it. There is no COBOL compiler in this environment.

The port will be run on extracts of a few to a few hundred records: ordinary district runs, and files that go through every path of the program, including rejected records, meter rollover, credit balances, very large commercial accounts, names of every shape, amounts on rounding boundaries, lines shorter than a full record, and files whose header record is missing or out of place. Each output file is compared byte for byte.
